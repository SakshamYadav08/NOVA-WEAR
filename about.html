The brand

Less noise. Better clothes.

NOVA / WEAR is the upgraded identity of the original E-Comm college project.

From classroom project to portfolio piece.

The supplied project started as a straightforward cloth shopping website with a homepage, category cards, offers, products and a cart page. This version keeps the original imagery and core idea while rebuilding the interface around a premium dark fashion system.

Designed for maintainability.

Products now live in one central JavaScript dataset. Shop cards, product detail pages, cart lines, wishlist items and related products are rendered from that same source. Cart, wishlist, demo authentication, coupons and orders use browser localStorage so the entire experience works without a backend.

Built for the next step.

The architecture intentionally stays framework-free: semantic HTML5, modern CSS and reusable Vanilla JavaScript. A real API, authentication service and payment provider can be connected later without rebuilding the visual layer.
